## [0.2.0-beta] — 2026-10-04

For learners starting from zero: the level is measured first, progress is remembered automatically.

### Added
- **Level gate and diagnostic** (`references/placement.md`): no lesson starts before the level is measured, even for `/learn-avalanche stage N`. At most 6 questions answered in the learner's own words; no score is shown; "I don't know" is valid. Four levels: `hiç-kod`, `js-python`, `solidity-başladı`, `kontrat-yazıyor`. The level is also adjusted live during lessons; `level` redoes the diagnostic (old results are kept).
- **Automatic memory:** the skill keeps its own file (`memory.md`), independent of the agent, and writes it at defined save points without asking. `scripts/memory.py` does find / init / set / append in a single tool call. Location: `~/.learn-avalanche/`, else `./.learn-avalanche/`; `LEARN_AVALANCHE_HOME` overrides.
- **Stage 1.5, early Fuji deploy** (when the wallet is ready) and a **closing idea card** (Stage 5): the learner writes five lines themselves.
- **Ecosystem programs** in `references/live-facts.md`, with a status note per row; the agent never states status, amounts or dates and points to the official page.
- `scripts/verify-facts.py` re-checks the five core facts in one command; `live-facts.md` older than 45 days triggers a staleness warning.
- Install with `npx skills add Anka-1623/learn-avalanche`; README, CONTRIBUTING, SECURITY, Code of Conduct, issue forms, pull request template; original pixel-art images generated by `tools/make-art.py`.
- Quality tooling: `tools/check-skill.py` (frontmatter, internal paths, links, compile, no personal paths) and `tools/test-memory.py` (unit tests for `memory.py`).

### Changed
- `progress.md` became `memory.md` and moved to the home folder; an old `progress.md` is migrated.
- Onboarding replies in **one language, the learner's** (any language, translated at runtime). The Team1 chapter no longer implies a language; it only changes badge name, example names and the closing suggestion. A short, warm opening and one open "goal" question replace the menu dump.
- The instructions have no per-language copies any more (no tr/fr/en opening lines, no language column, no closed language set). Arguments are understood by meaning in any language.
- Speed: the first reply runs a single tool call (`memory.py find`) and reads no other file; detail moved out of `SKILL.md` into `references/`.

### Fixed
- `LEARN_AVALANCHE_HOME` did not isolate: with an empty override folder the skill fell through to `~/.learn-avalanche/` and resumed someone else's memory. When set, it is now the only location.
- Stage files were referenced as `stages/…` but live in `references/stages/`, so agents read a missing path and searched for it. All internal references are now skill-root relative.
- `memory.py append` pads missing table columns; the `Şimdi` fields can be updated with `set` (no editor permission prompt).
- Tone: when a learner insists "just write the code", the agent no longer closes the door; dictation and a way back stay on offer.

### Known issues
- Codex can stall for about five minutes with `stream disconnected before completion: idle timeout waiting for websocket` (Codex to model backend, not the skill); it retries and then answers within seconds.
- Installed copies are snapshots; update with `npx skills update learn-avalanche`.

## [0.1.0-beta] — 2026-09-30

First release.

- `/learn-avalanche`: a teacher that takes a learner from zero Solidity to deploying a contract on their **own Avalanche L1**, using **Remix IDE + the Core wallet**.
- **Golden rule:** the agent writes no code; the learner does. Hint ladder (question → concept → shape in words → example from another domain → dictation); the solution is never written at any step.
- Onboarding by Team1 chapter (Türkiye / France / USA / Other).
- Six stages: Setup → Solidity basics (`BadgeBook`) → Contract design (`Badge`, ERC-721, roles, soulbound) → Security (write, exploit and fix a reentrancy bug) → Fuji deploy → Your own L1 + closing.
- `scripts/chain.py`: dependency-free, **read-only** chain checks (no keys, no signing); keccak-256 and EIP-55 cross-checked against `cast`. `scripts/fetch-doc.py`: Builder Hub pages as readable text, catching silent redirects of removed pages.
- `references/live-facts.md`: dated, re-verifiable Avalanche facts.
- `answer-keys/` (agent only) and `maintainers/forge-suite/run.sh`: Foundry regression suite with OpenZeppelin 5.6.1 (6 suites, 4 mutation tests).
- Out of scope for the beta: ICM/ICTT, automated testing, Foundry flow ([`roadmap-next.md`](.claude/skills/learn-avalanche/references/roadmap-next.md)); managed free L1 nodes expire after 3 days, so Stage 5 must be planned around that window.
