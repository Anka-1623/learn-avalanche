# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good faith, and keep discussion about the work. Many learners using this skill are beginners, and some are young: harassment, mocking someone's level, or pressuring anyone to share personal details or wallet secrets is never acceptable.

**Reporting:** use GitHub's *Report content* on the comment or issue, or message the repository owner privately through their GitHub profile. Reports are handled in confidence. The maintainers may edit, hide or remove contributions that break these rules.
